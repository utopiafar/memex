# ChatAgent 引用当天对话时日期偏到前一天

## 现象

ChatAgent 在引用过去的聊天内容时，可能会把当天发生的对话识别成前一天的对话。用户当天刚进行过的对话，在后续追问或引用历史上下文时，被 agent 以“昨天”或前一天日期来理解/表述。

## 可能问题

历史对话时间戳在进入 ChatAgent 上下文时可能存在 UTC 与本地时区转换偏移，或 prompt/context 中缺少明确的用户本地日期与时区信息，导致当天记录在日期归属上被回退一天。

## 期望

ChatAgent 引用历史对话时，应按用户本地日期正确判断“今天/昨天”等相对日期，尤其是当天产生的对话不应被归为前一天。
